Artifact Enhancements & Technical Reflection Narratives

1. Software Design & Engineering (CS-330: 3D Graphics & Visualizations)

Artifact Overview: The initial artifact was a legacy C++ OpenGL graphics application designed to render 3D geometric primitives and environment lighting.

Enhancements Implemented: Refactored the core rendering pipeline by implementing clean object-oriented principles, modularizing shader compilation, and enforcing strict memory management practices for vertex arrays and buffer objects. The overall application architecture was decoupled to separate rendering logic from user input processing.

Reflections & Outcome Alignment: Demonstrates mastery in software architecture, code modularity, and resource management. By refactoring tightly coupled code into extensible C++ modules, the software design adheres to industry standards for high-performance graphics applications.

2. Algorithms & Data Structures (CS-360: Mobile Architecture & Programming)

Artifact Overview: The original artifact was an Android mobile application built to store, retrieve, and manage itemized event and inventory records.

Enhancements Implemented: Refactored data handling algorithms by replacing inefficient array searches with optimized data structures (such as key-value maps and indexed lists). Optimized background thread execution and lifecycle management to prevent UI freezing and reduce memory overhead during large dataset queries.

Reflections & Outcome Alignment: Demonstrates algorithmic efficiency and trade-off evaluation. Improving computational complexity reduced runtime latency and resource usage on mobile hardware, achieving high performance while maintaining data integrity.

3. Databases & Security (CS-465: Full Stack Development / Travlr Getaways)

Artifact Overview: The baseline artifact was a full-stack web application incorporating a RESTful API and a MongoDB database for managing travel itineraries.

Enhancements Implemented: Hardened application security and database access control. Implemented schema-level data validation, sanitized user input to prevent injection attacks, implemented JSON Web Token (JWT) authentication for secure API endpoints, and encrypted sensitive payload data in transit and at rest.

Reflections & Outcome Alignment: Demonstrates a comprehensive security mindset and robust database practices. Incorporating defensive coding techniques and role-based access control ensures data privacy, mitigates adversarial exploits, and protects application resources against modern web vulnerabilities.
