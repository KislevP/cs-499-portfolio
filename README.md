Completing my B.S. in Computer Science at Southern New Hampshire University has been a transformative experience that solidified my expertise in software engineering, database management, and system architecture. Throughout this academic journey, I have developed a strong foundation in designing, implementing, and optimizing full-stack applications and standalone computing solutions. This ePortfolio showcases my growth and technical evolution by highlighting three key artifacts that demonstrate my mastery of software design, algorithmic optimization, and database security. My goal as a computer science professional is to leverage these full-stack and software engineering capabilities to deliver secure, performant, and user-centric software solutions in high-impact environments.

Course Outcomes & Demonstrated Strengths

Collaborative Environments & Communication: I consistently design and deliver professional-quality technical documentation, code reviews, and visual diagrams adapted for both technical teams and non-technical stakeholders. Through detailed README guides, code walkthroughs, and clear architectural documentation, I ensure complex technical decisions and trade-offs are transparent and accessible.

Algorithmic Solutions & Design Choices: I apply core data structures, algorithmic principles, and computational logic to solve complex computing problems. By refactoring legacy codebases, evaluating Big-O complexity, and optimizing execution paths, I balance performance, memory management, and design trade-offs to build scalable systems.

Innovative Tools & Computing Practices: Across my projects, I utilize modern frameworks, industry-standard languages (such as C++, Java, JavaScript, Python, and SQL), full-stack web stacks (MEAN stack), and version control systems. My work reflects modern software development standards, clean architecture, and modular design practices.

Security Mindset: Security and data privacy are integrated into every stage of my development process. I systematically anticipate adversarial exploits, validate input data, implement role-based access control (RBAC), hash sensitive credentials, and mitigate common vulnerabilities such as SQL injection, cross-site scripting (XSS), and unauthorized data access.
